# Operating rhythm

Use this cadence as a starting point and adjust it to your company stage.

- Monday: update metrics.
- Tuesday: run the weekly review.
- Wednesday: review risks and owners.
- Thursday: close decisions.
- Friday: roll decisions into next week and investor-safe notes.

## Weekly review questions

- What changed since the last review?
- Which output should the founder open first?
- What decision does this repo help make?
- Who owns the next action?
- What should be updated before the next run?
